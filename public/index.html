📖 Как пользоваться

Баланс = копилка (свободные + накопления) + подушка − долги.

День. Внесите доход, траты по категориям, погашение долгов, пополнение целей и подушки. «Не распределено» — остаток дохода. Если денег не хватает — выберите: не проводить, взять из копилки или создать долг.

Копилка. Свободные деньги и суммы целей/инвестиций.

Подушка. Цель = база × число месяцев. Рекомендация пополнения = остаток до цели ÷ дни периода. Если подушка ≥ цели — цель набрана.

Долги. Галочка «Деньги уже получил» зачисляет сумму в копилку (баланс не меняется). Дату создания можно менять в истории.

Накопления. «Потратить» — сумма становится расходом. «Закрыть» (инвестиция) — возврат; меньше вложенного = убыток.

Категории. «Отдано» — сколько ушло. Рекомендация = среднее за окно дней. Сброс не влияет на баланс.

График. Свечи показывают путь баланса. Нажмите на свечу для деталей. Зум: +/−.

AI-помощник. Вопрос по финансам — разбор ваших цифр. Память сохраняется в аккаунте.

Профиль. Данные синхронизируются между устройствами при входе.

Сохранение. Аккаунт — данные на сервере. Гость — только на устройстве. Экспорт JSON в настройках.
